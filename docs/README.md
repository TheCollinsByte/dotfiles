## 💡 Tips

### For First-Time Users
1. Start with the [main README](../README.md)
2. Follow the [Quick Install](../README.md#quick-install)
3. Check [LOCATION_GUIDE.md](LOCATION_GUIDE.md) to choose where to store dotfiles

### For Server Administrators
1. Read [SERVER_INSTALL.md](SERVER_INSTALL.md)
2. Use `--server` mode for headless systems
3. Consider `--minimal` for containers

### For Contributors
1. Review [CHANGELOG.md](CHANGELOG.md) for history
2. Check [TODO.md](TODO.md) for planned features
3. See [Contributing](../README.md#contributing) guidelines

## 📝 Documentation Standards

### File Naming
- `UPPERCASE.md` - User-facing documentation
- `.lowercase.md` - Internal/development notes

### Structure
- Clear headings and sections
- Code examples with syntax highlighting
- Tables for comparisons
- Lists for steps and features

### Content
- Concise and clear
- Examples for common use cases
- Links to related documentation
- Updated with each release
